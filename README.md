# web-01-html

## このリポジトリの目的

`web-01-html` は、Azure Cloud App開発へ段階的に進むための最初の学習用リポジトリです。
Webページの内容と構造を表す **HTML** と、それを読み取って画面を構築する **Webブラウザ** の役割を学びます。

題材は、機器の稼働状況を表示する「Machine Monitor」です。この段階では固定された情報を表示するだけにして、HTMLが担当する範囲に集中します。

## 学習するHTML要素

`index.html` を読み、ブラウザで表示することで次の内容を確認できます。

- HTML5文書の基本構造
- 文書の種類を宣言する `<!DOCTYPE html>`
- 文書全体を囲む `<html>`
- ブラウザ向けの情報を置く `<head>`
- 文字コードや表示領域を指定する `<meta>`
- ブラウザのタブに表示する名前を指定する `<title>`
- 画面に表示する内容を置く `<body>`
- 見出し、段落、リスト、リンク、テーブル、ボタン
- 内容に意味のある区切りを与える `header`、`nav`、`main`、`section`、`footer`

web-01-html/

## ブラウザで開く方法

サーバーやビルド作業は必要ありません。

1. このリポジトリをダウンロードまたはクローンします。
2. ファイル管理アプリでリポジトリのフォルダーを開きます。
3. `index.html` をダブルクリックするか、Webブラウザへドラッグ＆ドロップします。

ブラウザの「ファイルを開く」メニューから `index.html` を選ぶ方法でも表示できます。アドレス欄には、WebサーバーのURLではなく `file:///.../index.html` のようなローカルファイルの場所が表示されます。

## HTMLを開いたときに起こること

ブラウザは、おおむね次の順序でページを構築します。

1. `index.html` の文字データを読み込みます。
2. `<!DOCTYPE html>` を確認し、HTML5の標準的な解釈方法を選びます。
3. 開始タグ、内容、終了タグを解析し、要素同士の親子関係を持つ文書構造（DOMツリー）を作ります。
4. `head` の文字コード、表示領域、ページタイトルなどを解釈します。
5. `body` の見出し、段落、リスト、表などを、要素の意味とブラウザ標準の表示方法に従って画面へ配置します。

HTMLは「どの情報が見出しで、どの情報が表か」という**構造と意味**をブラウザに伝えます。このリポジトリにはCSSがないため、色や余白などにはブラウザが最初から持っている標準スタイルが使われます。またJavaScriptがないため、読み込み後に内容を書き換える処理はありません。

## `head` と `body` の役割

### `head`

`head` には、ページそのものについてブラウザへ伝える情報を置きます。通常、その内容は本文として画面には表示されません。

- `<meta charset="UTF-8">` は、日本語を含む文字をUTF-8として解釈するよう指定します。
- `<meta name="viewport" ...>` は、端末の画面幅を表示領域の基準にするよう指定します。
- `<title>` は、ブラウザのタブやブックマークで使われるページ名を指定します。

### `body`

`body` には、利用者が画面上で読む、または操作する内容を置きます。Machine Monitorの名称、説明、稼働状況、機器一覧、リンク、ボタンはすべて `body` の中にあります。

## 使用している主要HTML要素

| 要素 | このページでの役割 |
| --- | --- |
| `<!DOCTYPE html>` | この文書がHTML5であることをブラウザへ宣言します。HTML要素ではなく、文書の先頭に置く宣言です。 |
| `<html lang="ja">` | HTML文書全体のルート（最上位）要素です。`lang` は主な言語が日本語であることを示します。 |
| `<h1>` / `<h2>` | ページ全体の題名と、各内容の見出しを表します。見出しレベルによって文書の階層も示します。 |
| `<p>` | ひとまとまりの文章（段落）を表します。 |
| `<ul>` / `<li>` | 順番を持たない項目の集まりと、その各項目を表します。メニューと稼働状況に使用しています。 |
| `<a>` | `href` で示した場所へのリンクを作ります。このページでは同じ文書内の各セクションへ移動します。 |
| `<table>` | 行と列の関係を持つデータを表します。ページの見た目を整えるためではなく、機器情報を表形式で示すために使用します。 |
| `<caption>` | 表が何を示すかを表題として伝えます。 |
| `<thead>` / `<tbody>` | 表の見出し部分とデータ本体を区別します。 |
| `<tr>` / `<th>` / `<td>` | 表の行、見出しセル、データセルを表します。`scope` は見出しが対応する行または列を明確にします。 |
| `<strong>` | 内容の重要性を表します。このページでは機器名を強調しています。 |
| `<button>` | 利用者が操作できるボタンを表します。ただし、JavaScriptがないため、この段階では押しても処理は実行されません。 |
| `<header>` / `<main>` / `<footer>` | ページ上部、中心となる内容、ページ下部という大きな役割を表します。 |
| `<nav>` / `<section>` | ナビゲーションと、見出しを持つ内容のまとまりを表します。 |

### 属性にも注目する

開始タグの中にある `lang="ja"`、`id="overview"`、`href="#overview"`、`type="button"` などは**属性**です。属性は要素へ追加情報を与えます。たとえば、リンクの `href` に `#overview` を指定すると、同じ文書内で `id="overview"` を持つ要素へ移動できます。

## 意図的に使用していない技術

この段階では、HTMLの役割を明確にするため、次の技術を使用していません。

- CSS（装飾やレイアウト）
- JavaScript / TypeScript（動的な処理）
- React、Vue、AngularなどのWebフレームワーク
- Node.js、Python、FastAPIなどの実行環境やサーバー技術
- データベース
- Docker
- Azureサービス
- 外部ライブラリやCDN

そのため、Online / Offlineの表示は固定値です。「状態を更新」ボタンも見た目と意味を確認するための要素であり、まだ機能しません。
